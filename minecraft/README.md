# Minecraft Java minimap pack

`nminimap-c18b6e3b7ff8.zip` is the resource pack generated by this server's NMinimap 1.0.9-quickfix-1 installation. Minecraft downloads it when joining; players do not need to install a client mod.

SHA-1: `c18b6e3b7ff89e7648c46cd607489af9c6d335c5`

The pack's shaders and art come from [NMinimap](https://github.com/NezuShin/NMinimap/tree/V1.0.9-quickfix-1), licensed under GPL-3.0; see NMINIMAP-LICENSE.txt. [Corresponding source](https://github.com/NezuShin/NMinimap/archive/refs/tags/V1.0.9-quickfix-1.zip) includes the generator and its default resource assets. This ZIP was generated with the plugin's default shader parameters and contains no world files, player database, or server credentials.

This is the Java pack. Bedrock uses the separate pack sent by Geyser.
