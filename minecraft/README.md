# Minecraft Java minimap resource pack

Current pack: `nminimap-19876b851747.zip`.

SHA-1: `19876b851747f6267f01e90864aea199ddaec4ee`

Generated by NMinimap 1.0.9-quickfix-1, then patched to initialize `custom`, `uvCoord`, `b_meta`, and `box` at the start of the 26.3 text vertex shader. These values were previously unwritten on GUI/see-through paths and caused shader linking failures on the user's Mac. Initializers match the project's 26.2 shader. This is the only changed file inside the ZIP. Source GLSL is included in the ZIP; `fix-java-shader.py` documents the reproducible change.

The previous `nminimap-c18b6e3b7ff8.zip` remains available for reference; it failed to load on the Mac.

Shaders and art: [NMinimap](https://github.com/NezuShin/NMinimap/tree/V1.0.9-quickfix-1), GPL-3.0; see NMINIMAP-LICENSE.txt. [Corresponding upstream source](https://github.com/NezuShin/NMinimap/archive/refs/tags/V1.0.9-quickfix-1.zip) includes the generator and resource assets. No world files, player databases or server credentials are included.

This is the Java pack. Bedrock uses a separate pack sent by Geyser.
